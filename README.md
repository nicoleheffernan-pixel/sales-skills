# Sales Skills for Claude

Claude skills for B2B sales work, built by Nicole Heffernan with Claude.

| Skill | What it does |
|---|---|
| [cold-call-coach](cold-call-coach/) | Prep, rehearse and score B2B cold calls (SDR/BDR outbound) in English or Spanish (Spain): interview mock calls, real call cards, role-play with a scorecard, objection handling, voicemail and follow-up email. |

## Install a skill

- **Claude.ai**: zip the skill folder (for example `cold-call-coach`) and upload it under Settings > Capabilities > Skills.
- **Claude Code**: copy the skill folder into `~/.claude/skills/`.

Each skill folder has its own README with examples and sources.
